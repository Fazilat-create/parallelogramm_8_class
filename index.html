📚 Справочник · Четырёхугольники

🔷 Параллелограмм

Свойства
  • Противоположные стороны равны: $AB = CD$, $BC = AD$
  • Противоположные стороны параллельны
  • Противоположные углы равны
  • Сумма углов при одной стороне = $180^\circ$
  • Диагонали точкой пересечения делятся пополам
Признаки
  • $AB = CD$ и $AB \parallel CD$
  • $AB = CD$ и $BC = AD$
  • Диагонали делятся пополам

🟦 Прямоугольник

Свойства
  • Все свойства параллелограмма
  • Все углы прямые ($90^\circ$)
  • Диагонали равны: $AC = BD$
Признаки
  • Параллелограмм с прямым углом
  • Параллелограмм с равными диагоналями

🟡 Ромб

Свойства
  • Все свойства параллелограмма
  • Все стороны равны
  • Диагонали перпендикулярны
  • Диагонали — биссектрисы углов
Признаки
  • Параллелограмм с равными сторонами
  • Параллелограмм с перпендикулярными диагоналями

🟪 Квадрат

Свойства
  • Все свойства прямоугольника и ромба
  • Все углы $90^\circ$, все стороны равны
  • Диагонали равны, перпендикулярны, делятся пополам
  • Диагонали — биссектрисы (по $45^\circ$)
Признаки
  • Прямоугольник, который ромб
  • Ромб, который прямоугольник

🟢 Трапеция

Общие сведения
  • Две стороны параллельны — основания
  • Сумма углов при боковой стороне $180^\circ$
Равнобедренная трапеция
  • Боковые стороны равны
  • Углы при каждом основании равны
  • Диагонали равны

📐 Формулы

Угол правильного $n$-угольника
$\alpha = \dfrac{(n - 2) \cdot 180^\circ}{n}$
Сумма углов $n$-угольника
$S = (n - 2) \cdot 180^\circ$
Теорема Пифагора
$c^2 = a^2 + b^2$
Признаки равенства треугольников
  • По двум сторонам и углу между ними
  • По стороне и двум прилежащим углам
  • По трём сторонам
